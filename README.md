# Jacqueline P. Hodges Trichology Laser Center: Site Preview

A static preview of the new Shopify site, for client review only. It is not the live store.

## Publish with GitHub Pages

1. Create a new repository on GitHub (public, or private on a paid plan).
2. Upload everything in this folder to the root of the repository: `index.html`, the `images` folder, `.nojekyll`, and this README.
3. Go to **Settings > Pages**.
4. Under **Build and deployment**, set Source to **Deploy from a branch**, choose **main** and **/ (root)**, then click **Save**.
5. After a minute or two the preview is live at `https://<your-username>.github.io/<repo-name>/`.

## Notes

- Use the menu at the top to move between pages.
- Buttons that lead to checkout, product pages, or store policies show a short notice instead, since those only work on the real Shopify store.
- The page is set to stay out of search engines.
